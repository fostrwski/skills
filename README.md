# skills

My Claude skills for bridging design and engineering: design systems, frontend code and shipping, my way.

## Skills

| Skill | Use it for |
|---|---|
| [`fostrwski-way`](./fostrwski-way/SKILL.md) | Code shape, lint, typing, imports, styling, git and review rules for large frontend codebases. |
| [`better-design-system`](./better-design-system/SKILL.md) | Stack-agnostic rules for building, reviewing and auditing design systems and component libraries. |

## Layout

One folder per skill, each with a `SKILL.md`:

```text
<skill-name>/
  SKILL.md
```

## Install

Copy a skill folder into `~/.claude/skills/` (personal) or `.claude/skills/` (per project).
